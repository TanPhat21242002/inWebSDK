# Getting Started with Create React App

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

1. Run protection server:

2. If you run Protection Server on different port then need to modify file public/index.html

Need to replace line with link to DrawingWeb library
``` html
<script src="http://localhost:8080/DrawingWeb.js"></script>
```

3. Need to install and  run script:
npm install
npm start
